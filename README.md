## technews-today

Projeto desenvolvido com foco em praticar conceitos modernos de **CSS**, criando uma interface visualmente agradável sem utilizar frameworks ou JavaScript.

## 🛠️ Tecnologias

- HTML5
- CSS3
- GitHub

## 🎯 Objetivo

Criar uma interface moderna utilizando apenas **HTML e CSS** a partir de um modelo disponibilizado pelos professores, colocando em prática conceitos como:

- Glassmorphism
- CSS Grid
- Gradientes
- `position: sticky`
- Responsividade
- Organização e otimização do CSS

## 📱 Responsividade

O projeto utiliza **Media Queries** para adaptar o layout a diferentes tamanhos de tela, garantindo uma boa experiência em dispositivos móveis.

## 🚀 Regras do desafio

> **Somente CSS:** não utilizar frameworks, bibliotecas ou JavaScript.

> **HTML intocável:** toda a estilização deve ser feita sem modificar a estrutura HTML existente.


## ✨ Resultado

Uma interface moderna, responsiva e estilizada com **Glassmorphism**, seguindo todas as restrições propostas.
